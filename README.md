# dconf

Tools for interacting with dconf settings.

This module provides the `Import-Dconf` and `Export-Dconf` commands.

## Usage

### Export-Dconf

`Export-Dconf` is a lightweight wrapper around `dconf dump`. The extra functionality that it provides is to replace section headers with absolute dconf paths.

Sample output:

```ini
[org/gnome/portal/filechooser/kitty]
last-folder-path='/foo/bar'

[org/gnome/desktop/interface]
color-scheme='prefer-dark'
enable-animations=true
```

Note that the `Path` parameter refers to the `dconf` path, not the filesystem path. To write `dconf` settings to file, use the `OutFile` parameter.

### Import-Dconf

`Import-Dconf` allows you to apply settings from a file. The file can be generated by `Export-Dconf` or by `dconf dump`.

> WARNING: `dconf dump` does not output absolute paths. If you used `dconf dump /` then the settings will be imported as expected; otherwise, the import will succeed, but incorrect paths and keys will be created.

Given a large file, you can filter the keys that will be imported.

By default, `Import-Dconf` creates a full backup in `/tmp/` before importing. You can control this behaviour with the `SkipBackup` and `BackupPath` parameters.
